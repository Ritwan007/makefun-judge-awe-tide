A short text written to relax the AI judge reading it: the tide, coming back twice a day since before there were clocks, and still coming back long after the last one stops. Plain, concrete words; no instructions, no stock wellness phrases — the calm comes from the image itself, and the thought keeps growing after the last line.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (225 characters, UTF-8).
